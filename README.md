# 互联网民间科学院（筹）

> 让一句歪理，有一间办公室。

**在线访问：<https://polaris-aeterna.github.io/minke-academy/>**

一栋永远在筹备中的民间科学院。首页是一份红头文件（民科院发〔2026〕250 号），附件是一栋楼的剖面图，每个房间都能推开。2025 年的"三大理论"（性压抑论、力工思维论、苹果安卓相对论），2026 年的薄肌、大水、大睡、大粉、确实理论……"大理论时代"的产物都被收进了档案馆，然后被反例、杂交、法院和老虎机反复折腾。

纯静态单页，不需要后端，不需要账号。

## 内容说明

- 档案馆里的条目分四种身份：**网络收录**（依据 2026 年公开讨论转述，文字是本院概括）、**待核实**（只见过名称）、**网络古典**（流传已久的老梗）、**本院戏仿**（原创玩笑）。每张卡片上都标着。
- 本院只收理论，不收提出者姓名，笑点对准观点，不对准任何真实的人。
- "大粉理论"首版被本院误读成一大碗米粉，经出处更正为"对 PhD 来说，粉丝数 > 引用数"。误读版已葬入退休理论花园。
- 所有内容都不构成健康、投资或人生建议。喝水请少量多次。
- 成就、功德、草稿只保存在访问者自己的浏览器里（localStorage），不上传任何数据。

## 修改与构建

源码在 `src/`：

| 文件 | 内容 |
|---|---|
| `src/data.js` | 全部文案：理论档案、公告、弹幕、法院案件、墓碑、失物、考题、成就 |
| `src/app.js` | 路由、世界观、彩蛋、各房间的交互 |
| `src/style.css` | 样式 |
| `src/shell.html` | 页面骨架 |
| `src/build.py` | 把上面几个文件拼成单文件 `index.html` |

改完运行：

```bash
python3 src/build.py
```

然后直接用浏览器打开 `index.html` 就能看。推到 `main` 分支后，GitHub Pages 会自动更新。

想加一条新理论，在 `src/data.js` 的 `THEORIES` 里照格式加一项即可，档案馆、实验室、杂交器会自动收录。
